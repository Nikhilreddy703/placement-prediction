## 5. Metric Analysis: CV F1 vs Test F1 (KNN 0.8065)

In earlier reports, the best model (KNN) displayed identical values for `F1` and `CV F1` (`0.8065`).
Inspection of the exact unrounded floating-point calculations confirmed:
* **KNN 5-Fold Cross-Validation F1 on `X_train`:** `0.8064902016...` -> `round(..., 4) = 0.8065`
* **KNN Test Set F1 on `X_test` (50 / 62):** `0.8064516129...` -> `round(..., 4) = 0.8065`
* **Finding:** This was **not a display bug or copy-paste error**. The mean cross-validated F1 on 320 training rows and the test F1 on 80 held-out rows happened to be within $0.000038$ of each other, resulting in the identical 4-digit rounded decimal. Other models in the benchmark table showed distinct values (e.g., Random Forest: Test F1 0.8361 vs CV F1 0.7957).

## 9. Dataset Provenance

* **Origin:** `data/raw/placement.csv` was generated synthetically by running `src/generate_sample_data.py` (committed at initial baseline `4eb30e4`).
* **Ground-Truth Label Formula:**
  ```python
  z = (0.07*(ssc_p-67) + 0.05*(hsc_p-66) + 0.12*(degree_p-66) + 0.03*(etest_p-72) + 0.05*(mba_p-62) + 1.2*(workex=="Yes") + 0.4 + normal(0, 0.8))
  placed = random() < 1 / (1 + exp(-z))
  salary = np.where(placed, rng.integers(200000, 400000), np.nan)
  ```
* **Implications:**
  1. Logistic Regression outperforms tree models because the data-generating process is an additive logistic linear model with Gaussian noise.
  2. The data demonstrates pipeline integrity, but **cannot** represent real student career outcomes, demographic equity, or actual industry hiring.
